# Research questions — PROVISIONAL

These questions are provisional, not final. No novelty or contribution claim has been established.

## RQ1 — PROVISIONAL

How does existing literature handle ambiguous outcomes of state-mutating tool operations, and which mechanisms such as verification, replay, deduplication, idempotency, compensation, and transactional execution are used?

## RQ2 — PROVISIONAL

How does replaying an already-generated tool request differ from re-invoking an LLM to regenerate the action after an ambiguous tool outcome?

## RQ3 — PROVISIONAL

To what extent have these retry semantics been evaluated using real state-mutating external systems rather than controlled or simulated tool environments?
