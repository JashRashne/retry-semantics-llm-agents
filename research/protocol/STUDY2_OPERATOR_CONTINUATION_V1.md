failure can prevent finalization; absence of a valid final summary is incomplete.
The inventory detects accidental changes; it is not an external timestamp or
cryptographic signature.

Readiness qualification is performed at launch, so this code preparation does not
claim that credentials, provider permissions, model availability or remote quotas
have already passed a live check.
